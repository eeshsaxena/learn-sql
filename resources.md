# Resources

Recommended free/standard resources to go alongside these notes. The notes here
are original; use these for video explanations, extra practice, and depth.

## YouTube (popular for Indian placement prep)
- **CodeWithHarry** — beginner-friendly SQL/DBMS playlists in Hindi.
- **Striver / takeUforward** — structured CS + SQL sheets and interview prep.
- **Love Babbar** — DBMS one-shot / interview-focused videos and DSA+CS sheets.
- **Gate Smashers** — thorough DBMS lecture series (great for normalization,
  transactions, concurrency — very exam-oriented).
- **Apna College** — SQL/DBMS placement playlists.

(Search the channel name + "DBMS" or "SQL" — they each have a full playlist.)

## Practice platforms
- **LeetCode** — Database problems (see this repo's [`leetcode/`](leetcode/README.md)).
- **HackerRank** — SQL track (Basic → Advanced), good for syntax fluency.
- **StrataScratch / DataLemur** — real interview SQL questions.
- **SQLZoo** and **Mode SQL Tutorial** — interactive browser lessons.
- **db-fiddle.com** — run MySQL snippets online with no install.

## Documentation & references
- **MySQL Reference Manual** — https://dev.mysql.com/doc/ (the source of truth).
- **PostgreSQL docs** — excellent explanations even if you use MySQL.
- **use-the-index-luke.com** — the best free guide to indexing/performance.

## Books (if you want the classic theory)
- *Database System Concepts* — Silberschatz, Korth, Sudarshan ("the cow book").
- *Fundamentals of Database Systems* — Elmasri & Navathe.
- *SQL in 10 Minutes a Day* — Ben Forta (quick, practical SQL).

## GeeksforGeeks
Solid, searchable articles for every DBMS topic (normalization, ER, transactions,
indexing) and lists of interview questions — good for quick revision.

---

**How to combine them:** learn a concept from the [theory notes](dbms-theory/00_index.md)
here → watch one video (Gate Smashers/CodeWithHarry) if it's fuzzy → practice the
matching queries in [`lessons/`](lessons/) and [`leetcode/`](leetcode/README.md).
Understanding + reps is what sticks.
